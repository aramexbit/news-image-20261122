# The World in One Day — Sunday 22 November 2026

A one-page newspaper front page that sums up Sunday 22 November 2026
in a single image: 55 stories, 6 regions, every one dated that Sunday.
Three lead stories (186 drones over Ukraine, the Hong Kong vote, India
declare 720/9 in Wellington), nine more stories that moved the day, a
world map with all 55 stories pinned, a DATE CHECK box listing what was
deliberately left out, and 43 more stories in brief. Every scene is
drawn in code — no photographs, no AI images.

## Run it

```sh
python3 main.py
```

This writes `out/entry.png` (1024x1024, under 1 MiB). If Pillow is not
installed, the program falls back to copying `assets/prebuilt.png` to
the output instead. The render is fully deterministic: no clock, no
randomness, no network.
